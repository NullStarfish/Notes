terminology:
$x^{(i)}$: input variables/features
$(x^{(i)}, y^{(i)})$: training example
$\{(x^{(i)}, y^{(i)}); i = 1,...,n\}$: training set
$X, Y$: space of the input/output values
to learn a function $h: X \to Y$ 
$h$: hypothesis(假设)
